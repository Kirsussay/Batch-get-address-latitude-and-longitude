# WebGIS - OpenLayers + Vue 3

基于 Vue 3 + Vite + OpenLayers 的 WebGIS 应用，支持高德地图、天地图、OSM 底图切换，以及地址搜索与地图标注功能。

## 功能

- 🗺️ 读取xls和xlsx文件，批量获取地址的经纬度

# 使用方法

本项目是新手所作，使用时在项目文件夹创建一个.env文件，并添加两行代码` VITE_TIANDITU_KEY=`“你的天地图密钥”；`VITE_GAODE_KEY=`“你的高德地图密钥”

## 技术栈

- Vue 3 (Composition API + `<script setup>`)
- Vite
- OpenLayers
